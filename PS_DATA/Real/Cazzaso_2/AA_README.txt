A file with extension .tsc is a Time series Collection file
It is a python dictionary with the following content:

  absolute_timeline: time Series with the absolute number of days from the first measurement (the timeline)
  relative_timeline: time Series with the relative number of days between two subsequent dates (time baseline)
  u: array of the unwrapped time series
  w: array of the wrapped time series
  kd: array of the integer time series that represent the numbers of 2π wraps
